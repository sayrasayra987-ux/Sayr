# Neon Strike - HTML5 Space Shooter Game

A complete, ready-to-play arcade space shooter with neon graphics, particle explosions, waves of enemies, and smooth controls for both mobile (touch/drag) and desktop (keyboard/mouse).

## How to play

- Open index.html in any browser (phone or laptop) - no installation needed.
- Mobile: drag your finger to move the ship. Firing is automatic.
- Desktop: arrow keys to move, or drag with the mouse. Firing is automatic.
- Avoid enemy ships and pink bullets. You have 3 lives.
- Score grows with each kill. Every wave gets faster and adds tougher enemies.

## Game features

- 3 enemy types: scouts, gunships (they shoot back) and heavy cruisers with health bars
- Particle explosions and screen shake
- Parallax starfield and nebula background
- Progressive waves with rising difficulty
- Auto-fire, triple-shot upgrade at higher waves
- High-score tracking per session
- Fully self-contained single HTML file, no internet needed to play

## How to put it online (free)

- Netlify Drop: drag this folder onto app.netlify.com/drop and the game is live in seconds.
- Or itch.io for selling/hosting games.
